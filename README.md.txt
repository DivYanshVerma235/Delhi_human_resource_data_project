# Delhi Human Resource data analysis

## Overview

This project analyzes Delhi districts using crime, demographic, and economic indicators.

The objective is to integrate multiple datasets and apply statistical analysis to understand district-level patterns.


## Modules

### Module 1
Crime Data Collection and Feature Engineering

### Module 2
Demographic Data Collection

### Module 3
Economic Data Collection

### Module 4
Merging all datasets

### Statistical Analysis

- Descriptive Statistics
- Data Visualization
- Normalization
- Correlation Analysis
- Principal Component Analysis (PCA)



## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook
